6 · Statistical modelling — mouse-to-human transfer

Notebooks: Modelling/6_Statistical_Modelling.Rmd · 6_Statistical_Modelling_optionB.Rmd

Feature layers→ LOCO folds→ 4 algorithms→ Out-of-fold scores

Universes & targets

  • Universe 1 — all human DEGs (p_adj_human <= 0.05)
    • Convergence · rank transfer · direction
  • Universe 2 — mouse LEGs (Shared vs Mouse only)
    • Shared-LEG classification, ranks within LEGs
  • Absolute rank — percentile (0–100) of |log2FC| × -log10(adj. P)

Feature layers

  • DGE Baseline — mouse log2FC, 1/SE, mouse rank
  • Mouse + layers — adds sequence evolution, TFs, cCREs, BTM
  • Full + BTM — framing A (predictive) vs B (explanatory)

Algorithms (LOCO)

  • Linear / logistic regression
  • Lasso (glmnet)
  • Random forest (ranger)
  • Neural network (nnet)

Best out-of-fold results

  • Rank transfer — RF R² = 0.234
  • Direction — RF ROC-AUC = 0.849
  • Shared LEGs — Lasso 0.617 / 0.627

Outputs

  • score_shared · score_rank
  • score_direction · score_translational
  • Modelling/Models · Tables · Figures
